# Чек-лист самопроверки

Пройди перед тем, как отдать правленый текст.

## Смысл
- [ ] Все факты, цифры, условия и ограничения из оригинала сохранены.
- [ ] Ни один факт не выдуман. Где не хватало — стоит `[факт: ___]`.
- [ ] Термины аудитории не заменены на «простые» слова, которые звучат глупо для неё.

## Читатель
- [ ] Понятно, для кого текст и что он должен сделать после прочтения.
- [ ] Текст про читателя и его пользу, а не про автора и компанию.
- [ ] Каждое действие можно представить: нет абстракций вроде «повысить эффективность».

## Стоп-слова
- [ ] Нет вводных и связок без смысла.
- [ ] Нет усилителей («очень», «крайне», «максимально»).
- [ ] Оценки заменены фактами или убраны.
- [ ] Нет штампов и корпоративных клише.
- [ ] Нет канцелярита: «осуществлять», «является», «в целях», «данный».
- [ ] Отглагольные существительные превращены в глаголы.
- [ ] Нет «более», «от», «ряд», «некоторые» там, где есть число.
- [ ] Нет брехни: фраз, которые ни правда, ни ложь.
- [ ] Нет страдательного залога без необходимости. Понятно, кто делает.

## Синтаксис
- [ ] Одна мысль — одно предложение.
- [ ] Нет предложений длиннее ~20 слов без причины.
- [ ] Нет цепочек родительных падежей («улучшение качества обслуживания клиентов отдела»).
- [ ] Нет двойных отрицаний.
- [ ] Глагол стоит близко к подлежащему.

## Структура
- [ ] Заголовок обещает пользу или называет факт, а не тему.
- [ ] Первое предложение абзаца — его суть.
- [ ] Абзац = одна мысль.
- [ ] Перечисления из 3+ пунктов — списком, пункты параллельны.
- [ ] Главное — в начале. Хвост, который можно отрезать, отрезан.

## Тон
- [ ] Нет заискивания, извинений за текст, давления и приказов.
- [ ] Текст спокойный и прямой, но не сухой.

## Уровень
- [ ] `light`: структура и заголовки не тронуты.
- [ ] `normal`: тон автора сохранён.
- [ ] `hard`: текст стал заметно короче, а не просто «почищен».

## Разбор
- [ ] Каждая правка в разборе объяснена категорией и причиной.
- [ ] Пустые разделы убраны.
- [ ] Посчитано: было N слов → стало M.
